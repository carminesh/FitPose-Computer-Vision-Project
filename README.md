# Fit Pose: Real-time Fitness Tracking Using MediaPipe

This project uses **MediaPipe** to track and analyze fitness exercises like squats,push-ups and biceps curl. It leverages computer vision techniques to count repetitions and evaluate the correctness of movements, providing real-time feedback for fitness enthusiasts and professionals.

## Features

-   **Real-time Exercise Tracking**: Tracks body movements during exercises.
-   **Repetition Counter**: Automatically counts the number of repetitions.
-   **Form Evaluation**: Assesses the correctness of the exercise form based on predefined thresholds.
-   **Customizable**: Easily extendable for additional exercises.

## Technology Stack

-   **MediaPipe**: Used for pose estimation and skeletal tracking
-   **React.js**: Frontend framework for building the user interface
-   **React Webcam**: Enables webcam integration in the browser
-   **Tensorflow**: Open-source platform for machine learning developed by Google

## Prerequisites

-   Node.js (v14+ recommended)
-   NPM or Yarn
-   Webcam-enabled device (for real-time tracking)
